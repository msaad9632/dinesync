# DineSync — Frontend

React + Vite single-page app for the DineSync restaurant reservation system.
See the [project README](../README.md) for the full write-up, screenshots, and setup instructions.

```bash
npm install
npm run dev      # starts the Vite dev server on http://localhost:5173
npm run build    # production build
npm run lint     # eslint
```

Requires the backend API running on `http://localhost:5000` (see `../backend`).
